## 一、产品概述

### 1.1 产品定位
AI Workspace 是一款本地桌面 AI 工作空间应用，让用户通过自然语言与 AI Agent 协作，Agent 可自主规划任务、调用工具、执行操作，帮助用户高效完成日常工作。

### 1.2 核心价值
- **Agent 自主规划**：用户只需描述目标，Agent 自动拆解任务、编排步骤、逐步执行
- **本地安全可控**：数据留存本地，支持私有化模型部署，满足金融行业合规要求
- **多模型灵活调用**：支持 OpenAI / Claude / 本地模型等多 LLM 供应商切换与编排
- **工具生态开放**：内置文件操作、代码执行、网络搜索等基础工具，支持自定义扩展

### 1.3 目标用户
| 用户类型 | 典型场景 |
|----------|----------|
| 开发者 | 代码生成/重构、调试、项目脚手架搭建 |
| 知识工作者 | 文档撰写、数据分析、信息检索与整理 |
| 运维人员 | 脚本执行、日志分析、自动化巡检 |

## 三、核心功能模块

### 3.1 对话中心 ⭐⭐⭐

**功能描述**：用户与 AI Agent 的主要交互界面，支持多轮对话、上下文记忆、富文本渲染。

| 功能项 | 优先级 | 说明 |
|--------|--------|------|
| 多轮对话 | P0 | 支持流式输出、Markdown 渲染、代码高亮 |
| 会话管理 | P0 | 多会话切换、会话重命名/删除、会话搜索 |
| 上下文注入 | P1 | 支持上传文件/图片作为对话上下文 |
| 对话分支 | P2 | 从历史消息分叉，探索不同路径 |
| 工作模式切换 | P0 | Craft（直接执行）/ Plan（先规划后执行）/ Ask（仅问答） |

**交互规格**：
- 输入框支持多行，Shift+Enter 换行，Enter 发送
- 支持 @ 提及文件、文件夹、工具
- 支持 / 斜杠命令快速触发功能
- Agent 执行工具时实时展示执行进度

---

### 3.2 Agent 自主规划与执行 ⭐⭐⭐

**功能描述**：Agent 接收用户目标后，自动拆解为子任务、编排执行顺序、调用工具完成，全程可视化。

| 功能项 | 优先级 | 说明 |
|--------|--------|------|
| 任务自动拆解 | P0 | Agent 将用户目标拆解为可执行的子任务列表 |
| 任务看板 | P0 | 可视化展示：待执行/执行中/已完成/失败 |
| 执行过程可视化 | P0 | 每个工具调用展示输入/输出/耗时，可展开查看详情 |
| 人工确认节点 | P0 | 危险操作（删除文件、发送邮件等）需用户确认 |
| 任务暂停/继续/取消 | P1 | 用户可随时干预 Agent 执行过程 |
| 执行回滚 | P2 | 支持撤销 Agent 已执行的文件变更 |

**Agent 循环流程**：
```
用户目标 → 分析意图 → 拆解任务 → 选择工具 → 执行操作 → 观察结果 → 判断完成？
     ↑                                                        ↓ 否
     └────────────── 调整策略 ←───────────────────────────────┘
                                                            ↓ 是
                                                        汇报结果
```

### 3.6 技能系统 ⭐⭐

**功能描述**：技能（Skill）是 Agent 能力的结构化封装，将特定领域的知识、工作流和工具调用组合成可复用的能力单元，让 Agent 从"通用助手"进化为"领域专家"。

**核心理念**：
- 技能 = 领域知识 + 工作流程 + 工具编排 + 触发规则
- 用户可通过自然语言让 Agent 自动匹配并加载技能
- 技能可积累、可共享、可迭代，越用越强

| 功能项 | 优先级 | 说明 |
|--------|--------|------|
| 技能定义与存储 | P0 | 每个技能包含 SKILL.md（元数据+指令）、脚本、参考文档、资源文件 |
| 技能自动匹配 | P0 | Agent 根据用户意图自动识别并加载相关技能，无需手动选择 |
| 技能市场 | P1 | 内置技能库，按类别浏览（开发、写作、数据分析、运维等），一键安装 |
| 技能安装/卸载 | P0 | 支持从市场安装、从本地目录导入、从 URL 导入 |
| 技能安全审计 | P0 | 安装前自动检测技能安全性（P0/P1/P2 风险等级），高风险需用户确认 |
| 技能自学习 | P1 | Agent 完成复杂任务后，自动沉淀为可复用技能，避免重复探索 |
| 技能版本管理 | P2 | 技能更新追踪、回滚到历史版本 |
| 技能开发指引 | P1 | 内置技能创建向导，引导用户编写 SKILL.md 和配套脚本 |
| 用户级/项目级技能 | P0 | 用户级技能跨项目可用，项目级技能仅在特定项目上下文中生效 |

**技能结构示例**：
```
skills/
├── code-review/              # 技能目录
│   ├── SKILL.md              # 技能元数据（名称、描述、触发条件、指令）
│   ├── scripts/              # 配套脚本
│   │   └── analyze.py
│   ├── references/           # 参考文档
│   │   └── best-practices.md
│   └── assets/               # 资源文件
│       └── template.html
├── daily-report/
│   └── SKILL.md
└── data-analysis/
    └── SKILL.md
```

**SKILL.md 模板**：
```markdown
---
name: code-review
version: 1.0.0
description: 代码审查专家，自动分析代码质量、安全隐患和优化建议
triggers:
  - 代码审查
  - code review
  - 审查代码
  - 检查代码质量
category: 开发
author: Leon
---

# 代码审查技能

## 指令
当用户请求代码审查时，按以下步骤执行：
1. 读取目标文件/目录
2. 分析代码结构、命名规范、潜在 Bug
3. 检查安全漏洞（SQL注入、XSS等）
4. 生成审查报告，按严重程度分级

## 约定
- 使用中文输出审查报告
- 安全问题标记为 🔴 严重
- 性能问题标记为 🟡 建议
- 风格问题标记为 🔵 轻微
```

**技能生命周期**：
```
发现需求 → 编写/安装技能 → 自动匹配加载 → 执行任务 → 反思改进 → 更新技能版本
     ↑                                                          ↓
     └──────────── 沉淀新技能 ←── 复杂任务自动提取 ←──────────────┘
```

## 七、关键交互流程

### 7.1 Agent 自主规划执行流程

```
1. 用户输入目标："帮我把项目里的 TODO 注释都整理成列表"
2. Agent 分析 → 拆解任务：
   ├── 扫描项目目录结构
   ├── 搜索所有文件中的 TODO 注释
   ├── 提取并分类 TODO 内容
   └── 生成 TODO 列表文档
3. 展示任务计划 → 用户确认
4. 逐步执行：
   ├── [执行中] 扫描目录... → ✅ 找到 23 个文件
   ├── [执行中] 搜索 TODO... → ✅ 找到 15 条 TODO
   ├── [执行中] 提取分类... → ✅ 分为 3 类
   └── [待确认] 生成文档 → 用户确认 → ✅ 已写入 TODO.md
5. 汇报结果："共找到 15 条 TODO，已整理至 TODO.md"
```

### 7.2 工作模式交互

| 模式 | 触发方式 | Agent 行为 |
|------|----------|------------|
| Craft | 默认 / 输入"直接做" | 立即执行，完成后汇报 |
| Plan | 输入"先规划" / 点击Plan按钮 | 先展示计划，用户确认后执行 |
| Ask | 输入"只回答" / 点击Ask按钮 | 仅回答问题，不执行任何操作 |
