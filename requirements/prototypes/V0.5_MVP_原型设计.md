## 二、组件设计

### 2.1 Header 组件

| 元素 | 说明 |
|------|------|
| Logo/标题 | "🤖 AI Workspace" |
| Agent 选择器 | 下拉菜单，当前选中的 Agent |
| 设置按钮 | 打开设置面板 |

### 2.2 ChatPanel 组件

| 元素 | 说明 |
|------|------|
| 消息列表 | 滚动区域，显示所有消息 |
| 消息气泡 | 用户消息右对齐，助手消息左对齐 |
| 流式输出 | 助手消息逐字显示 |
| Markdown | 支持代码块、列表、粗体等 |

**消息气泡样式：**
- 用户消息：`background: #e3f2fd; border-radius: 16px 16px 4px 16px;`
- 助手消息：`background: #f5f5f5; border-radius: 16px 16px 16px 4px;`

### 2.3 InputArea 组件

| 元素 | 说明 |
|------|------|
| 输入框 | 多行文本输入，placeholder 提示 |
| 发送按钮 | 点击或 Ctrl+Enter 发送 |
| 模型选择 | 当前使用的模型 |

**快捷键：**
- `Enter`：发送消息
- `Shift+Enter`：换行

### 2.4 AgentList 组件（复用现有）

| 元素 | 说明 |
|------|------|
| Agent 卡片 | 显示名称、角色、模型 |
| 预设模板 | 快速创建预设 Agent |
| 新建表单 | 创建自定义 Agent |

## 三、交互流程

### 3.1 发送消息流程

```
用户输入 → 发送请求 → 显示用户消息 → 调用 Ollama API
    ↓
接收流式响应 → 逐字更新助手消息 → 完成 → 保存对话历史
```

### 3.2 选择 Agent 流程

```
点击 Agent 选择器 → 显示 Agent 列表 → 选择 Agent
    ↓
更新当前 Agent → 清空聊天区域 → 显示欢迎消息
```

## 四、页面状态

### 4.1 加载状态

- 首次加载：显示 "加载中..." 骨架屏
- 发送消息：输入框 disabled，显示 "发送中..."
- 接收响应：消息气泡显示加载动画

### 4.2 错误状态

- Ollama 未启动：提示 "请先启动 Ollama"
- 网络错误：提示 "网络连接失败"
- 模型不存在：提示 "模型不存在，请检查配置"

### 4.3 空状态

- 无对话历史：显示欢迎消息和使用提示
- 无 Agent：显示 "请先创建一个 Agent"

## 六、技术实现

### 6.1 前端新增文件

| 文件 | 说明 |
|------|------|
| `src/components/ChatPanel.tsx` | 聊天主面板 |
| `src/components/ChatMessage.tsx` | 单条消息 |
| `src/components/InputArea.tsx` | 输入区域 |
| `src/hooks/useChat.ts` | 聊天逻辑 Hook |
| `src/types/chat.ts` | 聊天相关类型 |

### 6.2 后端新增命令

| 命令 | 说明 |
|------|------|
| `call_model_stream` | 流式调用模型 |
| `get_conversations` | 获取会话列表 |
| `save_conversation` | 保存会话 |
| `get_conversation_history` | 获取历史消息 |

### 6.3 API 设计

**聊天请求：**
```typescript
interface ChatRequest {
  agentId: string;
  message: string;
  stream: true;
}
```

**聊天响应（SSE）：**
```
event: content
data: {"chunk": "你"}

event: content
data: {"chunk": "好"}

event: done
data: {"totalTokens": 100}
```
